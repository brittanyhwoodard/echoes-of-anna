# Echoes of Anna — Narrative Decision Engine & UI Prototype

**Echoes of Anna** is a narrative-driven, decision-based interactive fiction prototype developed as a systems engineering design project for Intro to Software Engineering (SE 2200). 

The project models how player agency and branching dialogue affect long-term narrative states. The focus was on applying the Software Development Life Cycle, specifically requirements engineering (SRS), user flow modeling, iterative prototyping, and scripting state-driven branching paths.



##  Playable Demos & Design Artifacts

- **Playable Web Export (Act I):** [Play on itch.io](https://brittany2003.itch.io/echoes-of-anna-act-i)
- **Interactive UI/UX Prototype:** Built in Figma to model screen layouts, hover states, and navigational branching.



##  Architecture & Tools

- **Narrative Logic & State Tracking:** Written in **Ink** (Inkle Studios) using the **Inky IDE**. Handled variable declarations (e.g., tracking player metrics like *trust*, *curiosity*, and *autonomy*), isolated node testing, and conditional story routing.
- **UI/UX & Prototyping:** Designed high-fidelity, high-contrast user interfaces in **Figma** focusing on accessibility, clean hierarchy, and dialogue terminal aesthetics.
- **Systems & Navigation Flow:** Modeled complete decision trees, state initialization, and game loops using **Draw.io**.



##  Systems Engineering Highlights (SDLC & Requirements)

- **Requirements Engineering:** Mapped core gameplay loops directly to functional requirements (FR1–FR6) and non-functional requirements (NFRs for accessibility, readability, and performance).
- **Branching Decision Trees:** Mapped multi-choice selection points to dynamic narrative scenes and variable adjustments.
- **Accessibility by Design:** Incorporated high-contrast typography, speaker color-coding, and adjustable font/volume overlays within the interface specifications.
- **Iterative Version Control:** Maintained structured development milestones from initial draft (v1.0) to final functional prototype evaluation (v2.0).
